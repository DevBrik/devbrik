# DevBrik

Bibliothèque de briques de code locales, partagées, testées et notées par les développeurs africains.
Projet de l'équipe « Les Lions et les Lionnes du code » pour le concours CADEV.

- Dossier de référence : docs/DevBrik-dossier-de-reference-complet.md (fait foi)
- Stack : Angular 21 + Angular Material, Spring Boot 4.1.1 (Java 21), PostgreSQL 18, Flyway, Docker, Nginx
- Branches : jamais de commit direct sur main, une branche feature/m<numéro>-<sujet> par tâche
